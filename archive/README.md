# Archive Directory

This directory contains historical documentation, one-time migration scripts, and data files from the STEELIQ project development. These files have been archived to maintain a clean project root while preserving historical context.

## Directory Structure

### `/historical/`
Contains phase completion reports and weekly status updates from earlier development phases (January - July 2025). These are superseded by the current Wave 3 implementation (October 2025).

### `/analysis/`
Contains Fortune 500 comparison documents and system analysis reports. Key information has been extracted and consolidated into the main `replit.md` file.

### `/planning/`
Contains strategic planning documents, roadmaps, and feature specifications. Critical elements have been incorporated into the current architecture documentation.

### `/documentation/`
Contains various implementation guides, calculation methodologies, and system integration reviews. Essential information has been preserved in `replit.md`.

### `/migrations/`
Contains one-time database migration and data manipulation scripts used during development. These scripts:
- Created database tables
- Fixed schema issues
- Populated initial data
- Updated existing records
- Tested various calculations

### `/data/`
Contains CSV exports and JSON data files including:
- Steel catalog exports
- Material data
- Analysis reports
- Import/export templates

## Important Note
All critical information from these archived files has been consolidated into `/replit.md`, which serves as the single source of truth for the STEELIQ project architecture and Fortune 50 compliance requirements.
