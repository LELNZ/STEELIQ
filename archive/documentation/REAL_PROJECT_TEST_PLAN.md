# Real Project Test: Industrial Mezzanine Floor Structure

## Project Overview
**Client**: Stryde Construction  
**Project**: 12m x 8m mezzanine floor for warehouse  
**Scope**: Complete structural steel package including stairs, handrails, and access platform  
**Design Load**: 3.5kPa live loading with AS1170 compliance  
**Estimated Duration**: 3-4 weeks fabrication + 1 week installation
