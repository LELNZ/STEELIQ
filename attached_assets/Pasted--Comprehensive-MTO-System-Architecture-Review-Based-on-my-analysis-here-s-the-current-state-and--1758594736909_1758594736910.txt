🔴 Critical Architecture Gaps
1. Incomplete Operation Coverage
Current system only handles connection types (stiffener, endplate, baseplate, cleat, bolt, weld). Missing:

Fabrication: Cutting, Drilling, Grinding
Surface Treatment: Blasting, Priming, Painting
Handling: Crane ops, Transport, Storage
Assembly: Fitting, Rigging, Installation
2. One-Way Data Flow
Current: Materials → Labor (✅)
Missing: Labor → Materials (❌)
         Consumables ↔ Materials (❌)
         Coatings ↔ Materials (❌)
3. Schema Misalignment
The MaterialChildItem type union doesn't support new operation types, preventing proper routing and bi-directional sync.

4. Dialog Limitations
"Add Connection Detail" is connection-centric, not pulling from Operations Settings for cutting/drilling/labor operations.

Phase 1: Unified Operation Model
Create a single OperationItem entity in schema:

// shared/schema.ts
export const operationItems = pgTable("operation_items", {
  id: serial("id").primaryKey(),
  estimationId: integer("estimation_id").references(() => estimations.id),
  parentMaterialId: varchar("parent_material_id"), // Link to parent material
  
  // Core fields
  category: varchar("category"), // fabrication|connection|assembly|surface|handling
  type: varchar("type"), // cutting|drilling|welding|grinding|blasting|painting|etc
  description: text("description"),
  
  // Quantities & Measurements
  quantity: numeric("quantity"),
  unit: varchar("unit"),
  unitCost: numeric("unit_cost"),
  
  // Operation-specific data
  thickness: numeric("thickness"),
  size: varchar("size"),
  length: numeric("length"),
  diameter: numeric("diameter"),
  area: numeric("area"),
  weldTime: numeric("weld_time"),
  
  // Routing fields
  laborHours: numeric("labor_hours"),
  consumablesData: jsonb("consumables_data"),
  coatingData: jsonb("coating_data"),
  
  // Source tracking
  sourceType: varchar("source_type"), // manual|library|standard
  sourceId: integer("source_id"), // ID from library/standards
  
  createdAt: timestamp("created_at").defaultNow(),
  updatedAt: timestamp("updated_at").defaultNow()
});
