III. Specification Document

1. Inputs:

Accepted File Types: PDF, DWG, DXF, IFC, RVT

Project Type: Residential / Commercial / Industrial

Scope: Structural Steel, Architectural Metalwork, Sub-assemblies, Site Install

2. Outputs:

Material Take-Off (Editable)

Labour Hours Breakdown

Costing per Unit, Phase, Total

Quote PDF

Audit Log & Versioning

CNC-ready formats

3. Features:

Smart Drawing Classification

OCR & Vector Analysis

Profile Detection & Mapping

Surface Area / Weight Calculations

Cost Estimation Engine (Materials + Labour)

Staging/Phase Logic

Editable, Shareable MTO Interface

Drawing Click-through Links

Change Tracking (Rev A to Rev B)

Export Templates

4. AI Models & Tools:

OCR: Tesseract or Azure Computer Vision

Drawing Analysis: DXFParser, IfcOpenShell

AI Detection: YOLOv8, Detectron2

Frontend: React, Fabric.js, Autodesk Viewer

Backend: Python FastAPI + Node.js

Data: PostgreSQL, S3

5. Roadmap:

Phase 1: MVP – PDF/IFC to MTO + Viewer

Phase 2: Rate Matching + Quote Builder

Phase 3: Phase Tracking + Multi-user Review

Phase 4: Historical Benchmarking + Revision Delta AI

Phase 5: BIM Full Integration + CNC DXF Output
